# Contributing to Silvatide Cottage

First off, thank you for considering contributing to Silvatide Cottage! It's people like you that make this project such a great landing page.

## Guidelines for Opening Issues
- **Bug Reports:** Describe the bug in detail, including steps to reproduce, expected behavior, and actual behavior. Include browser and OS details.
- **Feature Requests:** Explain what feature you want and why it would be useful for the project.

## Guidelines for Pull Requests
1. **Fork the Repository:** Fork the project and create a new branch from `main`.
2. **Branch Naming:** Use clear branch names based on the feature or fix: `feat/add-new-animation`, `fix/gallery-alignment`.
3. **Commit Conventions:** Follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:
   - `feat:` A new feature
   - `fix:` A bug fix
   - `docs:` Documentation only changes
   - `style:` Changes that do not affect the meaning of the code (white-space, formatting, etc)
   - `refactor:` A code change that neither fixes a bug nor adds a feature
   - `perf:` A code change that improves performance
4. **Code Standards:** 
   - Ensure all CSS follows the 8px spacing grid system.
   - Limit paragraph text blocks to a `max-width` of `400px` for optimal readability.
   - Write clean, semantic HTML inside Astro components.

## Submitting Your PR
1. Ensure your code builds locally without errors (`npm run build`).
2. Push your branch to your fork.
3. Open a Pull Request against the `main` branch of this repository. Include a clear description of the changes.

We will review your PR as soon as possible!
