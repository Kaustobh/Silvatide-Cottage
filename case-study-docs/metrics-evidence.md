# Metrics & Evidence

**What should go inside:** Performance scores (Lighthouse), accessibility audit results, load times before/after, or qualitative feedback from users/stakeholders.
**Why it matters:** Hiring managers want proof that your design works and drives results.
**Evidence to gather:** Lighthouse screenshots, W3C validation, bundle sizes, or user quotes.
**How it supports the final case study:** Proves you are a results-oriented UX Engineer.
