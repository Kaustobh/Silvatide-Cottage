# Silvatide Cottage: Bridging Luxury UI Design and Performant Web Architecture

**Role:** End-to-End Product Designer & UX Engineer
**Timeline:** [Insert Timeline, e.g., 2 Weeks]
**Tech Stack:** Figma, Astro, HTML, Vanilla CSS, JavaScript
**Domain:** Real Estate / Luxury Hospitality

## Project Overview
Silvatide Cottage is a conceptual luxury retreat designed for vacationers seeking an escape from city chaos. The objective was twofold: design a visually stunning, high-end booking experience in Figma, and then engineer it into a lightning-fast, production-ready web application. 

The ultimate goal was to prove that image-rich, bespoke luxury layouts do not have to compromise on web performance or accessibility.
